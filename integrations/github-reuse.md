# Reuse from GitHub

Repository: `https://github.com/taitgoodwin-gmail/design-knowledge-base`. Use an authenticated checkout or an authorized GitHub connection for this private collection.

Use a release tag or commit for repeatability. Read README.md and select the relevant guidance; record the exact commit and source IDs in the project. A remote URL alone does not load its contents into every future chat.

Codex reads project `AGENTS.md` instructions at session startup according to the documented hierarchy. Add a short pointer in each new product repository, then verify a new session can retrieve and summarize the required files. [Official instruction discovery](https://learn.chatgpt.com/docs/agent-configuration/agents-md), checked 2026-09-20.

Use the copy-ready [build handoff](../workflows/start-a-build.md). An agent unable to access this private repository should report that limitation instead of claiming it followed the guidance.
