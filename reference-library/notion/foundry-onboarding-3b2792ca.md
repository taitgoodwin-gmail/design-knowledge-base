**For any new team member or virtual role.**
## 5-minute essentials
1. **Single entry point** — Always start with `00-foundry` (the orchestrator).
2. **Order is fixed** — Whitespace → Concept → Brief → Craft. Never skip upstream steps.
3. **Appetite is sacred** — Locked in Whitespace and travels verbatim. Vague Appetite = discard.
4. **Brakes must bite** — Explicit kill criteria. Softening a KILL is an anti-pattern.
5. **One home per fact** — Locked fields never reinterpreted. Decision Log is the history.

## How to run a cycle
1. Invoke `00-foundry` with current domain / candidate state.
2. Follow the skill it routes you to.
3. Produce the required artifact.
4. Log disposition + rationale in the Decision Log.
5. Create a Cycle page: `Cycle YYYY-MM-DD – [Short Candidate Name]`
## Locked rules (never soften)
- Appetite required and locked from Whitespace
- Future Customer Experience paragraph required on every GO
- Explicit kill criteria (no soft kills)
- UI/Accessibility hard constraint (WCAG 2.2 AA subset + selected Nielsen + ≤60s + one primary path)
