# Design system and quality bar

Read this for art direction, design-system decisions, reference analysis, or quality review.

## Experience brief

Define before styling:

- primary visitor and their first question;
- desired feeling in the first ten seconds;
- one primary action and one humane alternative;
- the proof needed before that action feels safe;
- brand tensions to balance, such as expert/human or precise/energetic;
- prohibited patterns, copied references, and unsupported claims.

## Native visual system

Design globally first, then locally:

1. typography roles and responsive scale;
2. color palette and section themes;
3. primary, secondary, and tertiary buttons;
4. spacing, content width, and section rhythm;
5. header/navigation and footer;
6. page sections and Fluid Engine compositions;
7. image crops, overlays, effects, and background treatments;
8. site-wide and component motion;
9. mobile-specific arrangements;
10. extensions or custom code only for a defined unmet effect.

## Top-tier rubric

These are review categories, not a percentile claim or mandatory scoring system. Evaluate visible results and record specific strengths, defects and corrective actions. Use numerical scoring only if the user chooses a rubric and thresholds.

| Category | What earns a high score |
|---|---|
| Composition | Deliberate hierarchy, tension, balance, and varied but coherent section rhythm |
| Typography | Distinct roles, strong scale, readable line length, careful wrapping, consistent details |
| Color | Purposeful relationships, adequate contrast, controlled accents, coherent themes |
| Assets | Original or properly licensed imagery/illustration with consistent art direction |
| Motion | Purposeful choreography, clear triggers/end states, static and reduced-motion alternatives |
| Mobile | Intentionally recomposed layouts, not merely stacked desktop blocks |
| Clarity/conversion | Rapid understanding, credible proof, obvious next step without coercion |
| Accessibility | Keyboard, focus, contrast, semantics, alternatives, zoom, readable targets |
| Performance | Optimized assets, restrained embeds/scripts, stable layout, acceptable loading |
| Originality/coherence | Recognizably project-specific and consistent across the full journey |

A candidate is not ready while required comprehension, accessibility, privacy or functional defects remain. No unapproved numerical threshold or average may hide a serious defect.

## Three-pass method

1. **Concept:** compare two or three original directions using the same content and rubric.
2. **System:** choose typography, color, spacing, buttons, asset language, section vocabulary, and motion grammar.
3. **Polish:** tune wrapping, crop, alignment, optical spacing, hover/focus states, motion timing, and mobile composition.

Do not expand a mediocre first page across the site. Prove the system on the priority journey first.
