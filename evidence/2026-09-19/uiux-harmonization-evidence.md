## Synthesis and proposed project practice

Use complementary roles: human-centred process and explicit user tasks; agreed accessibility constraints; heuristics as expert-review prompts; project design system as consistent implementation; representative user evaluation and outcome measures. This organization and conflict-resolution procedure are reviewer proposals, not a named external standard or a requirement from ISO.

For each decision record user task, observation, relevant requirement/guideline plus applicability, proposed implementation, validation method, observed result or unchecked status, source version/date, and reason for any departure from a recommendation. Avoid a composite design score that can conceal a failed requirement.

MindLeverX examples: retain essential sample status beside metrics while moving detailed methodology to accessible secondary content; preserve brand through compliant color choices; test visible versus collapsed navigation for relevant tasks rather than treat 1122px as a prescribed breakpoint. Previous navigation concern remains a research-supported hypothesis, not measured visitor behavior. All user-testing proposals remain unperformed.

Standing guidance supplies default WCAG 2.2 AA target. Source-backed principles do not establish that site already conforms. UI measurements and interaction checks remain scoped to those recorded in design-benchmark-evidence.md.
