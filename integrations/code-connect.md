# Code Connect handoff practice

Start with [developer handoff](../tools/figma/modules/10-dev-handoff.md) and its dated official sources. Establish the real component repository, exported component name, Figma node and supported properties before creating mappings.

Our acceptance checks: mapping resolves to the intended component; supported states/props are represented; generated code uses the real component; responsive and interaction behavior survives implementation. UI-based mapping and CLI-rendered code snippets are not interchangeable capabilities. Recheck current platform documentation and entitlements before configuring them.

No Code Connect mappings were created in this knowledge migration. Record an implementation in the product repository and a reusable lesson here after validation.
