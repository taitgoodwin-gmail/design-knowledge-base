## Standing rules for each run
- Never invent a date. If a page states no publication or updated date, record **not stated** — 114 of 149 current sources are in that category, so `last verified` carries almost all the freshness signal.
- Idempotent: update an existing entry in place, never append a duplicate.
- Record failures, redirects and dead pages rather than dropping them silently.
- A page that returns HTTP 200 is not necessarily still a distinct page — several now serve consolidated content under their old URL. Check the canonical URL, not just the status code.
- Write nothing outside this hub. Never edit a `CLAUDE.md` in a code repo.
