## Concept map

1. **User and task:** ISO human-centred design scope, UX beyond screens, Design Council Double Diamond.
2. **Understanding and navigation:** Norman's mental models, information scent, Nielsen heuristics, progressive disclosure.
3. **Presentation and interaction:** visual hierarchy, Carbon actions/motion/tokens, web versus platform guidance.
4. **Accessibility:** WCAG criteria and conformance scope; technical and user evaluation complement each other.
5. **Measurement:** component definitions and composite validity; HEART goals → signals → metrics.
6. **Research:** observations versus explanations; formative studies versus population estimates and causal experiments.
7. **Credibility:** source-to-claim fit, correct attribution, platform-specific applicability.

The harmonization method is our synthesis: establish the user task, identify applicable constraints, compare acceptable alternatives, then verify the specific outcome claimed. It is not an additional external standard.

## What has and has not been established

The collection contains expert review, limited browser checks, source research, teaching examples and a proposed study. No representative-user study, production experiment, full accessibility audit or site implementation was performed. The intended buyer audience remains provisional. Site observations are dated evidence, not a guarantee of current behavior.

This is all the saved work found here, organized for reuse. It is not a full conversation export or archive of raw browser screenshots/tool responses; those raw materials were not present as saved files. The manifest establishes preservation of the available files, not the independent truth of every claim.

Plain Markdown and JSON make this folder portable. No external account, synchronization, installed skill or plugin is required. A future session should be pointed to this README; storing a file does not automatically load it into every future conversation.
