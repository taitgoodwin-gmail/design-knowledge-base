# Design principles and their application

Read the [UI/UX playbook](uiux-design-playbook.md) for the reusable decision process and [worked cases](../learning/design-judgment-worked-cases.md) for handling competing guidance. The source catalog retains the original 41 source records and their limitations.

| Topic | Application |
|---|---|
| User research and usability | Establish the user's task and context; separate observed difficulty from its proposed explanation |
| Information architecture | Make labels and destinations match; use recognizable navigation and progressive disclosure |
| Typography, color and layout | Establish hierarchy, grouping, readable text and meaningful emphasis; exact styling remains a project choice |
| Accessibility | Apply relevant WCAG criteria and test real states; an automated score or selected contrast pairs do not establish conformance |
| Motion and interaction | Give movement an informational purpose; preserve task completion with reduced motion |
| Human–AI interaction | Explain capabilities and uncertainty; expose evidence, correction and recovery |

The [MindLeverX rationale](../projects/mindleverx/mindleverx-design-rationale.md) demonstrates element → principle → purpose → color/motion reasoning. Those concepts are hypotheses, not measured conversion results. Use the [element template](../templates/element-rationale.md) for another project.
