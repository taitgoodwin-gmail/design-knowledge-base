## Storage boundaries

This is a private repository containing a snapshot of the local design library taken on 20 September 2026. GitHub stores the committed documents, research records, previews, and imported artifacts. The editable Figma canvas remains in Figma; its link is recorded here. Website and application source remain in [MindLeverX](https://github.com/taitgoodwin-gmail/MindLeverX).

The initial import preserves the existing folder organization and file contents. Historical files may contain outdated paths or references. Imported source dates and evidence statuses have not been refreshed merely by publishing them. Consult current primary sources before using dated guidance for consequential decisions.

Local edits and Figma edits do not automatically synchronize to this repository. See the [import receipt](evidence/github-import-2026-09-20.md) and [SHA-256 inventory](evidence/github-import-manifest-2026-09-20.json) for exactly what was copied.
